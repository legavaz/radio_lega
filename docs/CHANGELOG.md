# История изменений

## 0.1 — 2026-11-01…02

Первая рабочая версия: своё радиоприложение вместо стороннего с рекламой.

### Каталог
- Клиент Radio Browser: перебор зеркал (`all`, `de1`), обязательный `User-Agent`
- Постраничная загрузка по 12 станций — сервер обрывает ответы >~18 КБ
- IPv4-only DNS и принудительный HTTP/1.1 (сеть не дружит с IPv6 и h2)
- Вкладки **Россия / Все / Избранное / Мои**, взаимоисключающие
- **Свои станции по URL**: добавление через «+», проверка адреса, удаление долгим нажатием
- Поиск по названию, жанру, стране внутри активной вкладки
- Кэш каталога на диск отдельно для каждого источника
- Логотипы с четырьмя запасными источниками и цветной буквой-заглушкой

### Воспроизведение
- `MediaSessionService` + ExoPlayer в foreground-сервисе
- HLS и ICY/MP3/AAC по MIME-типу
- Резервные потоки: переключение по ошибке, состояние сбрасывается на новой станции
- Управление из уведомления, гарнитуры, Bluetooth
- Пауза при отключении наушников
- Индикация ошибки потока в мини-плеере

### Удобство
- Избранное: из списка и из мини-плеера, отдельная вкладка
- Восстановление последней станции при запуске (с учётом «играла/пауза»)
- Таймер сна 15/30/45/60/90 минут, живёт в сервисе, команда через `MediaSession`
- Затухание звука в последнюю минуту перед остановкой — линейно от 1.0 до 0.0
- Встряхивание телефона продлевает таймер на тот же период: громкость
  возвращается мгновенно, играет короткий звук маракасов (можно отключить)
- Индикатор таймера в мини-плеере: луна по текущей фазе + обратный отсчёт
- Автопрокрутка к текущей станции — только если она вне экрана, чтобы список
  не прыгал при обычном тапе по станции
- Баннер про исключение из экономии батареи

### Сборка
- Release-сборка с R8 и `shrinkResources`: **3,0 МБ** против 20 МБ debug
- Подпись через `keystore.properties` (в git не попадает)
- `install.ps1` — сборка, установка, запуск одной командой
- Юнит-тесты на JVM: расчёт фазы Луны (9) и форматирование карточки станции (7)
- GitHub Actions: тесты + debug APK на каждый пуш в `main`
- Убран жёстко прописанный `org.gradle.java.home` из `gradle.properties` —
  из-за него падала сборка на CI (путь к JDK теперь только через `JAVA_HOME`)

### Откачено
- **ICY-«сейчас играет».** Обёртка над `DataSource` рассинхронизировала поток,
  звук начинал заикаться. Удалена, задача переоткрыта с другим подходом —
  см. `ARCHITECTURE.md`.

### Известные ограничения
- Луна рисуется на Canvas: фаза считается корректно, форма подобрана на глаз
- Каталог грузится 6–10 секунд из-за нестабильности API
- Нет жанровых подборок, истории прослушиваний и виджета
